# Research Workspace v1.0.4

Windows 10/11 x64 本地科研资料工作区：用思维导图组织项目、章节和附件，在本地保存与迁移资料。

## 安装与运行

从 GitHub Releases 下载 v1.0.4_Research_Workspace_Portable.zip，完整解压后运行 v1.0.4_Research_Workspace.exe。便携版包含 Python 3.12 与 Tk/Tcl 运行环境。

HTML 编辑器随软件打包，在本机浏览器应用窗口中显示；其余附件使用 Windows 默认应用打开。内置编辑器的导出文件直接保存到系统桌面，同名文件自动添加编号；头像和作者名称用于展示。软件数据写入用户选择的项目目录。

## 项目与导图

点击左侧“＋项目”，选择本地保存文件夹并输入项目名称。项目下可创建子文件夹和思维导图，子文件夹支持多级嵌套。每张新导图提供根节点和三级初始子节点。通过“打开项目”切换当前项目目录。

双击导图节点或大纲内容直接编辑，支持多行内容。节点是统一的内容框。父子节点按各自宽度排列，100% 缩放时水平间距为 56 像素。点击节点右侧箭头收起或展开子分支，折叠状态在思维导图与大纲之间同步；小比例缩放保留按钮的点击空间。大纲提供加大的展开箭头和勾选图标。

选中节点显示柔和金黄色加粗边框，大纲选中行使用淡色背景。选择父节点自动选择其全部后代，包括折叠节点，右侧汇总并选中关联附件。共享附件显示一份，可以在右侧调整导出范围。

## 附件与 HTML 修订

将文件从资源管理器拖到节点上，软件复制归档并为每个文件创建一个以文件名命名的子节点。原文件保留。

Word、Excel、PPT、HTML、Markdown 和图片显示不同的类型图标。单击文件图标或双击右侧附件列表打开附件。HTML/HTM 默认进入内置的 HTML 修订批注工具 v0.4.7，自动加载归档副本，支持修订、批注、高亮、画笔和保存归档；其他附件直接由默认应用打开。

导入 HTML 资源文件夹时可指定入口页，归档包含目录内的资源。单独导入 HTML 时，应将其依赖的本地图片、CSS 和脚本一起归档。

右侧附件列表支持 Ctrl/Shift 多选和导出，导出保留原文件名和格式，同名的不同文件自动添加编号后缀。

## 单文件项目包

左侧 Ctrl+单击多选项目、文件夹或导图，Shift+单击连续选择，右键“导出所选项目包…”生成单个 .rwp 文件。

项目包保存所选子树、导图、节点内容与样式、折叠状态、缩放和归档附件。选择单张导图时保存该导图及关联附件。共享附件和重叠子树保留一份。

将 .rwp 文件拖入软件窗口，选择本地还原位置，即可还原并打开项目。还原使用独立目录，已有同名目录时自动添加编号。后续修改保存到还原后的项目目录，需要再次传递时重新导出项目包。

## 常用操作

| 操作 | 方式 |
|---|---|
| 保存项目 | 左上角“保存”或 Ctrl+S |
| 编辑节点 | 双击节点或大纲内容 |
| 提交编辑 / 换行 / 取消 | Enter / Shift+Enter / Escape |
| 创建子节点 / 同级节点 | Tab / Enter |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 删除所选分支 | Delete |
| 选择或取消整个分支 | Ctrl+单击 |
| 选择连续范围 | Shift+单击 |
| 平移画布 | 左键拖动空白区域，或中键拖动 |
| 缩放 | Ctrl+滚轮 |
| 搜索 | Ctrl+F |

关闭窗口时可以选择保存、放弃或取消。删除节点、导图和文件夹后可撤销，归档文件保留；归档附件管理提供单独的永久删除操作。软件支持原子保存、快照恢复和项目目录单实例锁。

内置深蓝、青绿、浅灰、暖棕、暮紫五套主题，提供画布设置、缩略导航和全局搜索。

## 从源码运行与检查

使用官方 Python 3.12 x64，并确保包含 Tkinter。程序使用 Python 标准库。

    python app.py
    python test_workspace.py --headless --report test_results.json
    python test_node_flow.py
    python test_project_flow.py
    python test_package_flow.py
    python test_html_editor_flow.py

内置编辑器导出检查使用 Node.js 执行页面处理程序，并将文件写入临时桌面目录。

自动检查使用临时夹具和隐藏窗口。文件复制、项目包还原、层级与持久化、默认打开分派、内置 HTML 入口及 OLE 接口均有检查；Office 类型的测试文件用于核对字节复制与类型识别。

## 构建便携版

在 Windows 下运行：

    python build_portable.py

构建使用当前官方 Python 环境和系统 .NET Framework C# 编译器，输出至 dist。输出目录已存在时请另存现有构建再重新构建。测试报告生成后，可运行 finalize_delivery.py 校验并生成源码包、便携包和 SHA-256 清单。

源码主要由 app.py（界面）、workspace.py（存储与导出）、native_drop.py（Windows OLE 拖放）、html_editor.py（本机 HTML 编辑会话）和 themes.py（主题）组成。
